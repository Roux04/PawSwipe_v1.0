# PawSwipe_v1.0
PAWNDER: Your New Furry Friend Awaits!

This app is for pet owners, animal lovers, and anyone in the community who wants to lend a helping hand! Our app brings animal lovers together, through community postings, lost and found features, adoption, and more! Users can easily create postings for lost pets and share with a large community, or even just talk about their interests. Through Pawnder, we intend to build lasting connections and make a supportive environment for users and pets alike!

Key Features
- Filtering System: Users can filter their searches based on animal type & location, even going into deeper specifics (i.e. “orange fur”).
- Real-Time Messaging: Contact users in real time
- Posting: Creation of personalized posts, as well as interaction with posts from other users
- Tags: Users can identify certain likes, dislikes, etc with the tags on the posts
- Docker Database: A high performing database that keeps information well organized throughout different devices.

Tech-Stack
- Flutter: Framework used to develop the app
- Dart: Language used for frontend and backend development
- FastAPI: Helps with the algorithm for recommended posts, etc
- Python: Backend Development
- PostgreSQL:Database primarily used in the project
- PostGIS: Open-source extension for the PostgreSQL database that adds support for storing, indexing, and querying spatial data
- Docker: Database Interpreter, allows for a smooth run
